# Color

來源：Figma **MDS_Foundation › 顏色使用說明 / 輔助用色 / 交易狀態顏色顯示規範**；數值讀自 `guideline/Color_20261016 update/colors.css`（2026-10-16），Guideline 更新後本頁自動同步。

> 本頁表格同時列出 Light / Dark 數值。工具列切到 **Theme: dark** 時，頁面上的元件示意也會切換。

## 1. 色彩運用原則 Key Principles

1. **對比度**：文字與背景須符合 WCAG 2.0 AA。文字 &lt; 19px 對比度至少 **4.5:1**；文字 ≥ 19px 至少 **3:1**。元件容器與背景至少 **3:1**。
2. **基調**：KGI 數位觸點以白色與淺藍為基調，內容主色與輔色搭配少量藍色為強調色；插圖、圖表可用綠與橘做輔助色。
3. **比例**：畫面約 **70% 背景、30% 元素**；背景再分為主要 50%、次級 30%、點綴 20%。

## 2. 色彩名稱與意義 Color Naming

Figma 命名規則：**介面用途 / 顏色任務**，例如 `Content/Primary`。程式裡 `/` 改成 `-`、全小寫，前面加 `--color-`：

| Figma | CSS 變數 | Tailwind class |
|---|---|---|
| `Content/General/Primary` | `--color-content-general-primary` | `text-content-general-primary` |
| `Container/Card/White` | `--color-container-card-white` | `bg-container-card-white`、`border-…` |
| `Surface/Blue` | `--color-surface-blue` | `bg-surface-blue` |
| `Chart/Blue 1st` | `--color-chart-blue-1st` | `bg-chart-blue-1st`、`fill-…` |

| 介面用途 | 說明 | 用在 |
|---|---|---|
| **Surface** | 介面底色、區塊底色 | `bg-` |
| **Container** | 組件、元件容器背景色（含邊框、分隔線） | `bg-`、`border-` |
| **Content** | 文字、標題、標語、圖標、裝飾線 | `text-`（icon 用 `tint` 跟著文字色） |
| **Chart** | 圖表用色、插圖可用的擴充色盤 | `bg-`、`fill-`、`stroke-` |

顏色任務：**Primary** 主要／**Secondary** 次要（例如標題與內文）／**Tertiary** 三級（佔位詞、較不重要資訊）／**Active** 啟用、可點擊／**Positive** 成功／**Caution** 錯誤、警示／**Divider** 分隔線／**Disabled** 禁用／**Ascend** 升值／**Descend** 貶值。

## 3. Token 架構

```
色值 #0044AD  →  Global token（原始色票）sky-blue-600  →  Semantic token  container-general-active-primary
                                                                      └→ content-general-active
```

- 元件、頁面**只用 Semantic token**（Surface / Container / Content / Chart）。Dark Mode 只換 Semantic token 的對應，原始色票兩種模式相同。
- 原始色票只在特例使用（例如紅色「證」徽章），並以 `lint-allow` 標註；`npm run check:tokens` 會擋未標註的原始色票。

## 6. 內容色 Content

內容色的使用範圍包含文本、標題、標語、圖標等提供資訊或帶有意義的內容。對比度欄位是放在 `container-card-white` 上的計算值（Light / Dark）。

- **★ 重要且緊急**（Primary、Secondary、Tertiary、Active、Light Active、Caution）：對比度**必須** 4.5:1（AA）。
- **☆ 重要不緊急**（Ascend、Descend、Positive…）：對比度**建議** 4.5:1。
- **＊ 不重要不緊急**（Disabled）：依 WCAG 2.2，附帶性內容沒有對比度要求。
- `Light Active` 是放在深色容器上的白字，不適用白底對比度。

{CONTENT.map((g) => (
  <div key={g.group} className="sb-unstyled flex flex-col gap-8 py-16">
    <p className="t-subtitle-bold text-content-general-primary">{g.group}</p>
    <TokenTable rows={g.rows} showContrast />
  </div>
))}

## 7. 互動狀態 Hover & Disabled

**Hover 不是獨立色票**：由容器色 / 文字色的 HSB **Brightness** 運算（`npm run theme` 自動產生 `--color-*-hover`，class 為 `hover:bg-…-hover`、`active:bg-…-hover`）。

| Brightness | Light Mode | Dark Mode | 範例（Light） |
|---|---|---|---|
| ≤ 32% | +10% | +15% | hsba(216, 100%, 32%) → 42% |
| 33% ～ 86% | −10% | +10% | hsba(216, 100%, 68%) → 58% |
| ≥ 87% | −5% | −15% | hsba(0, 0%, 100%) → 95% |

<Box className="flex flex-wrap gap-16">
  {['container-general-active-primary', 'container-general-active-secondary', 'surface-white', 'content-general-active'].map((t) => (
    <div key={t} className="flex flex-col gap-8">
      <div className="flex gap-4"><Chip value={resolve(`--color-${t}`).value} size="size-48" /><Chip value={resolve(`--color-${t}-hover`).value} size="size-48" /></div>
      <code className="n-caption-regular text-content-general-secondary">{t}</code>
      <span className="n-caption-regular text-content-general-tertiary">{resolve(`--color-${t}`).value} → {resolve(`--color-${t}-hover`).value}</span>
    </div>
  ))}
</Box>

**Disabled**：容器一律 `container-general-disabled`、文字一律 `content-general-disabled`，不另做 hover。
