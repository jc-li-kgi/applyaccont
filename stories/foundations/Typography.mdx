# Typography

來源：Figma **MDS_Foundation › Typography、Typography Scale**；數值讀自 `guideline/Typography/kgi-typography.css`，Guideline 更新後本頁自動同步。1 rem = 16px。

## 1. 字型 Font Family

| 環境 | 中文 | 英文、數字 | 取得方式 |
|---|---|---|---|
| Web（含 Mobile web） | 思源黑體 Noto Sans TC | Montserrat | [Noto Sans TC](https://fonts.google.com/noto/specimen/Noto+Sans+TC)、[Montserrat](https://fonts.google.com/specimen/Montserrat)（Google Fonts） |
| iOS 原生 | 蘋方 PingFang TC | SF Pro | 系統內建，不需打包（[SF Pro](https://developer.apple.com/fonts/)） |
| Android 原生 | 思源黑體 Noto Sans CJK TC | Roboto | 系統內建；部分廠牌（三星、小米）會覆蓋系統字型，要求一致時把 Noto Sans TC 打包進 App |
| In-App WebView | 跟隨所在平台的原生字型 | 同左 | App 在 `<html>` 加 `data-platform="ios"` 或 `"android"` |

**設定原則**

- 全站只在根層設定一次字型：英數字型放第一順位、中文字型放第二順位；遇到中文時瀏覽器自動改用下一個字型。
- 元件、頁面**不要個別指定字體**。kit 只在 `base.css` 用 `var(--font-sans)` 設定一次（`npm run check:tokens` 會擋 `font-family`）。
- `--font-en`、`--font-tc` 只用在確定單一語言的元素（純數字金額、純英文品牌字、純中文標題）。
- `<html lang="zh-Hant-TW">` 必加，避免中文出現簡體或日文字形（Nuxt layer 已設定）。
- iOS App 語系要設為 zh-Hant，中文才會使用蘋方-繁。

**載入（Nuxt layer 已內建，下面是對照）**

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Montserrat:wght@300;400;500;600&family=Noto+Sans+TC:wght@300;400;500&display=swap">
```

```css
/* ========== CSS 字型定義 ========== */

/* Web（預設） */
:root {
  /* 一般情境：中英文混排時由瀏覽器逐字元判斷，自動分流至對應字體 */
  --font-sans: "Montserrat", -apple-system, "Helvetica Neue", Arial,
               "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif;
  /* 英數 Montserrat → 英文系統字（Montserrat 載入失敗時的備援）→ 中文思源黑體 → Mac 備援蘋方 → Windows 備援正黑體 → 系統字 */

  /* 僅限確定整個元素不會與中文混排的純英數情境（例如純數字金額、英文品牌字） */
  --font-en: "Montserrat", -apple-system, "Helvetica Neue", Arial, sans-serif;

  /* 僅限確定整個元素不會與英文混排的純中文情境 */
  --font-tc: "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif;
}

/* WebView iOS：跟隨原生字型（App 需在 <html> 加 data-platform="ios"） */
html[data-platform="ios"] {
  --font-sans: -apple-system, "PingFang TC", sans-serif; /* 英數 SF Pro → 中文蘋方 → 系統字 */
  --font-en: -apple-system, sans-serif;
  --font-tc: "PingFang TC", sans-serif;
}

/* WebView Android：跟隨原生字型（App 需在 <html> 加 data-platform="android"） */
html[data-platform="android"] {
  --font-sans: Roboto, "Noto Sans CJK TC", "Noto Sans TC", sans-serif; /* 英數 Roboto → 中文系統思源黑體 → 雲端思源黑體 → 系統字 */
  --font-en: Roboto, sans-serif;
  --font-tc: "Noto Sans CJK TC", "Noto Sans TC", sans-serif;
}

/* 使用：全站只在根層設定一次 */
body {
  font-family: var(--font-sans);
}
```

## 2. 字級 Typography Scale

為了提升閱讀體驗，提供**標準字級**與**加大字級**兩種版本，讓用戶依需求選擇。kit 目前只套用標準字級（加大字級見文末）。

- 終端設備：Web（寬度 ≥ 768，含平板）、Mobile web（&lt; 768）、APP iOS、APP Android。kit 依畫面寬度自動切換 Web / Mobile web；WebView 依 `data-platform` 改用原生字重與行高。
- 語言：`.t-*` 用於中文（含中英混排），`.n-*` 用於純英文、數字（金額、日期、帳號）。只要內容有中文就用 `.t-*`。
- 不要用 `text-sm`、`font-bold`、`leading-*`（kit 已移除 Tailwind 預設字級）。
- 數值格式：字級・字重・行高。

## 3. 用法

```html
<p class="t-headline text-content-general-primary">成功送出申請</p>
<p class="t-body-regular text-content-general-secondary">我們將在 1 小時內完成撥款。</p>
<p class="n-title text-content-general-primary">TWD 400,000</p>
```

- 每段文字都要有一個 `.t-*` 或 `.n-*`，顏色另外用 `text-content-*`。
- 元件裡的文字層級已內建（例如按鈕是 Subtitle-B、Tag 是 Caption-R），一般不需要覆寫。
