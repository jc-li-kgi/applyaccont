# 頁面描述範本（給 generate-ui skill）

複製下面這段，填寫後貼給 Claude。**標 ★ 的一定要寫**。其他沒寫會先從描述推斷；推不出、而且會影響版型的才追問（一輪最多 4 題）；其餘用預設值，做完會列出推斷與預設。
間距、顏色、字級、圓角都照 Guideline，不用寫。

```md
# ★ 頁面：<功能 › 頁面名稱>
- 類型：流程申請（借款、申請、開戶）／資訊瀏覽（帳務、總覽、首頁）（沒寫會從頁面名稱推斷）
- 平台：App / mWeb／Web／兩者（沒寫 = App / mWeb）
- 頁首：返回 + 標題「…」（子頁預設有返回、沒有分享；主頁沒有返回、有底部導覽）
- 步驟：第 N 步「…」／共 M 步（要寫總步數；沒有步驟就刪掉這行）
- 參考稿：<Figma frame 連結，沒有就留空>

## ★ 區塊（由上到下）
1. <區塊名稱，盡量用 Storybook 上的元件名，例如詳情卡、費用卡、條款、列表>：<內容>
2. …

## 底部
- 按鈕：<文字>（不固定（內容下方）／固定在底部／固定在底部 + 總計列／沒有按鈕）（沒寫：流程頁 = 不固定、列表頁 = 沒有按鈕）

## 互動 / 狀態
- 點「…」→ …（例如確認對話框 → 完成頁；沒寫就先顯示 Toast）
- 需要的狀態：錯誤／載入中（沒寫只做正常狀態；列表一律有空狀態）

## 特例（和規範不同才寫）
- 例：區塊 2 與 3 之間不留間距
```

## 範例

```md
# 頁面：股票借貸 › 確認申請
- 類型：流程申請
- 平台：App / mWeb
- 頁首：返回 + 標題「申請借款」
- 步驟：第 3 步「確認申請」／共 3 步

## 區塊
1. 詳情卡：借款金額 TWD 400,000；參考利率 2.8 %；手續費 TWD 2（ⓘ 說明：每筆借款收取手續費 TWD 2）
2. 費用卡「借款費用」：參考利率 2.8%、借款手續費 TWD 2；備註「費用僅供參考」
3. 條款：☐ 我已閱讀並同意〈借貸契約〉

## 底部
- 按鈕：「確認送出」，不固定；未勾條款時停用

## 互動
- 點「確認送出」→ 確認對話框（返回／確認送出）→ 完成頁「成功送出申請」
```
